# hello-oss-project

## Giới thiệu
Dự án mẫu nhỏ bằng ngôn ngữ C, in ra dòng chữ "Hello Open Source".

## Mục tiêu
- Thực hành xây dựng tài liệu cho dự án mã nguồn mở.
- Làm quen với quy trình README, CONTRIBUTING và LICENSE trên GitHub.

## Hướng dẫn build và chạy
Yêu cầu: trình biên dịch GCC.

    gcc hello.c -o hello
    ./hello

Kết quả mong đợi:

    Hello Open Source
